# SchemaFlow

SchemaFlow is a collaborative database schema designer similar to dbdiagram.io.

Core Features

- Infinite Canvas
- Database Tables
- Relationships
- Column Notes
- Version Review
- Publish Workflow
- Collaboration
- Google Authentication

Technology

Frontend

TypeScript
Vite
React Flow
Zustand
TanStack Query

Backend
